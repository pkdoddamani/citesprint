How measurement works

Plain English — no fake certainty

I run each buyer prompt many times and score how often your brand is named, including control prompts I don’t try to improve — so a null result is possible. Engine coverage is expanding; I’ll tell you exactly which assistants each report used.

What you’ll hear

Whether you’re often named but ranked late, strong only on niche wording (for example Playwright / synthetics), weak on other prompt types, or barely named at all. A nice website file alone usually doesn’t close those gaps.

What we won’t pretend

That one screenshot proves a win. That technical files fix rank by themselves. That anyone can guarantee ChatGPT will name you next week. If the baseline is null or flat, you’ll hear that first.

Score insight: Partial

Often named on API / uptime-style prompts, but ranked late in the shortlist. Stronger when buyers ask about Playwright / synthetics. Weaker on status-page-style prompts. Site files (robots, llms.txt, schema) helped clarity — they did not fix rank by themselves.

What that teaches (for any similar tool):
  • Being named is not the same as being ranked early — measure both.
  • Prompt type matters: niche wording (Playwright / synthetics) can look stronger than status-page prompts.
  • Missing FAQ and “vs” pages leave third parties in control of the story AI quotes.
  • Files alone don’t close the gap — quotable pages and mentions do more of the work.
