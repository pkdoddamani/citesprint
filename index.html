How measurement works

Plain English — no fake certainty

I run each buyer prompt many times and score how often your brand is named, including control prompts I don’t try to improve — so a null result is possible. I’ll tell you exactly which assistants each report used. Practice demos use what we can defend today: direct site checks, published ChatGPT/Gemini naming studies (e.g. Glotier), ChatGPT citation maps (e.g. Reditus), and clearly labeled inferred roundups — not invented “we measured ChatGPT + Perplexity + AI Overviews on every prompt” claims.

What you’ll hear

Whether you’re often named but ranked late, strong only on niche wording (for example Playwright / synthetics), weak on other prompt types, or barely named at all. A nice website file alone usually doesn’t close those gaps.

What we won’t pretend

That one screenshot proves a win. That technical files fix rank by themselves. That anyone can guarantee ChatGPT will name you next week. If the baseline is null or flat, you’ll hear that first.
